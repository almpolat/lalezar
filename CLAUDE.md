# Lalezar Çiçekçilik — demo site
Statik site: HTML + Tailwind CDN + vanilla JS. GitHub Pages'te, main branch, root.

## Dosyalar
- index.html, kategori.html, urun.html, sepet.html, bilgi.html, admin.html
- js/config.js: dükkan bilgileri + mode (demo/firebase)
- js/store.js: veri katmanı, tüm veri buradan okunur/yazılır
- js/seed.js: örnek ürünler, kategoriler, slider
- js/ui.js: header, footer, ürün kartı, sepet
- assets/styles.css: ortak stiller

## Kurallar

- Sadece istenen değişikliği yap, fazlasını ekleme.

- store.js'deki demo/firebase yapısını bozma.
